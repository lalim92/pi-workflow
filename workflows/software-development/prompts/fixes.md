# Software Development Workflow — Fixes

Apply only clearly in-scope technical fixes identified by the preceding review.

## Requirements

- Do not expand product scope.
- Do not make unapproved architecture or public API decisions.
- Run focused validation after fixes.
- Report applied and deferred findings.
- End with `WORKFLOW_STATUS: FIXES_COMPLETE`.
- End with `WORKFLOW_STATUS: BLOCKED` when user input is required.
