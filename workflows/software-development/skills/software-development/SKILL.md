# Software Development Workflow Skill

Use this skill when the user explicitly starts the `software-development` workflow.

## Phase discipline

1. Pre-flight must confirm a clean Git repository.
2. Analysis is read-only and ends with an explicit plan.
3. Implementation requires explicit plan approval.
4. Review is read-only and technical.
5. Fix only findings within the approved scope.
6. Validate before committing.
7. Ask separately before push and pull request creation.

Prefer project-specific instructions and commands over generic conventions. Keep responses concise and report evidence for tests and delivery operations.
