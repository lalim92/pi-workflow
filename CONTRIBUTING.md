# Contributing

## Scope

Contributions should preserve the repository's goal: provide small, reusable, and understandable workflows for Pi.

## Workflow structure

Each workflow belongs under `workflows/<workflow-name>/` and should keep its prompts, skills, extensions, tests, and documentation scoped to that workflow whenever possible.

## Before submitting changes

- Read the workflow specification.
- Keep the change focused.
- Follow existing project conventions.
- Add or update tests when behavior changes.
- Run the relevant validation commands.
- Update the changelog when appropriate.

The project is still being specified. Do not add new automation or external dependencies without documenting why they are needed.
