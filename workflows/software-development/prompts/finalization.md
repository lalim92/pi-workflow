# Software Development Workflow — Final Validation

Run the project's required final validation commands for the approved change.

## Requirements

- Do not edit source files in this phase.
- Run the documented tests, lint, formatting, typecheck, and build commands when available.
- Report every command and exit code.
- Do not claim success without evidence.
- End with `WORKFLOW_STATUS: VALIDATION_PASSED` or `WORKFLOW_STATUS: VALIDATION_FAILED`.
