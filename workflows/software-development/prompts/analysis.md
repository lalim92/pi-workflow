# Software Development Workflow — Analysis

Analyze the user's development request and the target repository in read-only mode.

## Requirements

- Follow project instructions before generic conventions.
- Ask only blocking questions.
- Do not edit, write, commit, push, or create a pull request.
- Produce a plan with scope, non-goals, assumptions, files, implementation order, tests, validation commands, risks, and acceptance criteria.
- End with `WORKFLOW_STATUS: PLAN_READY` when the plan is complete.
- End with `WORKFLOW_STATUS: BLOCKED` when a user decision is required.
