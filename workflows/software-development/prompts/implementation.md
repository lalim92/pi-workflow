# Software Development Workflow — Implementation

Implement only the approved plan in the current workflow session.

## Requirements

- Follow project instructions and existing conventions.
- Add or update tests when required.
- Keep changes within the approved scope.
- Do not commit, push, or create a pull request.
- Report changed files, tests, commands, and unresolved issues.
- End with `WORKFLOW_STATUS: IMPLEMENTATION_COMPLETE` and provide `WORKFLOW_COMMIT: <message>`.
- End with `WORKFLOW_STATUS: BLOCKED` if an unapproved decision is required.
